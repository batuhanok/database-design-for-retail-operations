# Database Design and SQL Analysis

A database design and SQL analysis project developed for a fictional retail company to organize and analyze customer, store, employee, product, order, manufacturer, and campaign data.

## Project Overview

The project includes the design and implementation of a structured database model, an E/R diagram, sample data, SQL queries, and an HTML/CSS report presenting the database structure and query outputs.

## Key Features

- Designed 7 core entities and their relationships through an E/R diagram
- Populated the database with 240 records
- Developed 11 SQL queries using:
  - Multi-table joins
  - Aggregations
  - Filtering
  - Grouping
  - Sorting
- Analyzed sales, customers, employees, campaigns, suppliers, and order-related data
- Presented database structures and query outputs in an HTML/CSS report

## Technologies

- SQL
- Microsoft SQL Server
- HTML
- CSS
